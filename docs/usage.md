# 使用指南

[返回 README](../README.md)

## 添加与分享

### TXT 导入与拖放

点击「导入 TXT」，或把 HTTP/HTTPS 链接、文本和普通 TXT 文件拖到添加区。查看有效、重复和无效候选后，点击「确认导入」。

TXT 使用 UTF-8（允许 BOM），链接可按换行、空白、中英文逗号分隔，省略协议时补全 HTTPS：

```text
https://example.com/archive.zip
example.com/document.pdf
```

每批最多 10 MiB、10000 条候选，单条最多 16 KiB；多个拖入文件合并计算。超限或非法编码会拒绝整批。拖放不接受目录、符号链接、二进制文件、`.url` / `.webloc` 快捷方式及其他下载协议。

预览不显示凭据或查询参数，确认时重新去重并应用当前设置。取消会停止后续处理，已成功创建的任务保留。拖放不可用时可改用粘贴或 TXT 导入。

### 剪贴板提示

在「设置 → 常规 → 剪贴板链接提示」开启，默认关闭。只处理开启后的新复制事件，仅识别显式 `http://` / `https://` 链接；普通域名和超过 1 MiB 的文本不参与解析。

点击「添加剪贴板链接」才会创建任务；「忽略」关闭本批提示，会话内会抑制重复提示。关闭功能或退出会清除候选，不保存剪贴板历史。提示不可用时使用手动粘贴。

### 导出清单

「导出清单」可导出所选或全部任务的 v1 JSON，包含文件名、脱敏 URL、大小、进度和状态。URL 凭据、查询串、片段、请求头、代理配置和本地绝对路径均不导出。

**清单用于分享，不支持备份恢复或 JSON 导入。** 去掉签名参数的链接可能无法下载。导出可取消，取消或失败不会覆盖原文件。

## 下载控制

### 队列与计划

等待任务可在详情或右键菜单中置顶、上移、下移。操作针对完整等待队列，与列表排序、搜索筛选无关，也不抢占正在下载的任务。顺序随任务保存，普通未完成任务重启后默认暂停。

在高级新建或详情的「下载计划…」中启用计划：

| 设置 | 规则 |
| --- | --- |
| 最早开始时间 | 当前本地时间 `YYYY-MM-DD HH:mm`；留空表示不限制 |
| 每日允许时段 | `HH:mm`，可跨午夜，如 22:00–06:00；包含起点、不含终点，起止不能相同 |
| 手动暂停 | 优先于计划；继续或重试仍需满足计划条件 |
| 禁用计划 | 暂停未完成任务，需手动继续 |

显式启用计划不受「添加后自动开始」限制。时段结束保留进度并释放连接；已启用且未手动暂停的计划会在重启后重新评估。应用未运行或电脑休眠时不调度，恢复后按当前时段判断，不补执行错过的时段；失败任务需手动重试。

### 限速与多连接

全局限速在设置中修改，单任务限速在高级新建或详情中修改。单位为 KB/s（1024 字节/秒），0 表示该层不限速；两层同时生效，运行中修改无需重连。允许少量短时突发，应在数秒窗口观察速度。

| 连接设置 | 默认 / 范围 | 生效时间 |
| --- | --- | --- |
| 新任务默认连接数 | 1 / 1–8 | 仅影响新任务 |
| 单任务连接数 | 继承默认值 / 1–8 | 任务下次开始 |
| 全局连接上限 | 16 / 1–64 | 立即限制后续请求；降低时等待已有请求释放 |

连接数指同时活动的下载请求，与「同时下载数」分别生效。文件至少 8 MiB，且服务端提供有效 Range、强 ETag 和未压缩的已知长度时才启用分片，否则使用单连接。多连接不保证提速，见 [测量结果](multi-connection-measurement.md)。

### SHA-256 校验

1. 在高级新建填写预期 SHA-256，或在详情中点击「保存摘要」。摘要为 64 位十六进制，留空表示不校验。
2. 下载完成后自动校验；已完成任务可点「重新校验」，校验过程中可取消。
3. 在详情查看匹配结果、实际摘要和校验时间。

下载完成与校验结果分开显示，完成通知仅表示传输完成；不匹配会保留文件，不自动重下。重启后保留历史结果，但当前状态回到待校验，需重新执行；历史匹配不代表文件此后未被修改。

### 更新失效链接

1. 暂停任务并等待连接停止，在详情或右键菜单选择「更新下载链接…」。
2. 填写新地址及所需请求头，点击「验证新链接」。失败或取消不改变旧地址和部分数据。
3. 点击「保存新链接」，再手动继续下载。任务及保存路径保留，旧认证清除。

只有同源、同路径、版本与长度一致，且已有数据逐字节比对通过时才复用进度；否则从头下载。验证会重新下载已有前缀或已提交分片，产生额外流量。新认证仍仅存内存。

## 保存目录

默认使用系统下载文件夹。在「设置 → 常规」修改默认目录，或编辑分类目录规则。规则按顺序匹配，首条启用且命中的规则生效：

| 类型 | 示例与边界 |
| --- | --- |
| 扩展名 | `zip` 与 `.ZIP` 等价；`tar.gz` 填 `gz` |
| 域名 | `example.com` 匹配该域名；`*.example.com` 只匹配子域 |
| 目标目录 | 必须为绝对路径；可用预览检查命中规则 |

高级新建中显式指定的目录优先；默认预填目录仍参与规则匹配。规则只按最初链接和创建时文件名判断，重定向或服务器改名不会重新分类。修改规则不移动已有任务，目录不可写时报告错误，同名文件自动避让。

## 代理与认证

在「设置 → 代理」选择直连、系统代理或自定义 HTTP/HTTPS/SOCKS5 代理，可配置认证、跳过列表并测试连接。

系统代理读取 Windows WinINet 或 macOS `scutil --proxy`，并支持 `HTTP_PROXY`、`HTTPS_PROXY`、`ALL_PROXY`、`NO_PROXY` 及其小写形式。不执行 PAC；仅有 PAC 时回退到环境变量或直连。跳过规则支持 `<local>`、`*.example.com`、`.example.com`、`host:port`、CIDR 和 `*`。修改只影响后续连接。

代理密码保存在系统凭据库，不写入设置 JSON；凭据库不可用时仅本次运行有效。

URL 认证和所有自定义请求头（含 Referer、Cookie、Authorization）仅存内存。重启后，在高级新建输入同一链接并补填认证，可沿用原任务、路径和进度。Range、If-Range、Accept-Encoding 等由引擎管理，不能自定义；跨源重定向会移除认证与自定义请求头。

## 详情与诊断

任务详情显示进度、速度、预计剩余时间、重试、续传能力和错误信息，也可复制脱敏诊断。

「最近 120 秒速度」统计实际接收量，包含多连接与重试流量。每秒最多采样一次，休眠或时钟跳变显示缺口；历史仅存内存，重启后清空。

「设置 → 关于 → 导出诊断日志」导出本次运行的脱敏 JSON，可取消，取消或失败保留原文件。日志最多 1000 条 / 1 MiB，容量满后淘汰旧事件并记录省略数，不自动写盘或发送遥测。

日志不含凭据、查询串、片段、请求头、响应体、代理密码、本地绝对路径或剪贴板原文，但仍包含来源主机和 URL 路径，分享前可检查内容。

## 数据与续传

在「设置 → 关于」查看数据目录。Windows 新安装通常为 `%AppData%\拾流\`；升级后若已有旧 `Downloader` 目录且新目录尚不存在，则继续使用旧目录及代理凭据。开发运行与安装版使用不同目录。旧版和新版请勿同时运行。

| 文件 | 用途 |
| --- | --- |
| `settings.json` | 设置，不含代理密码 |
| `tasks.json` | 任务记录，约每两秒及退出时保存 |
| `<文件名>.part` | 单连接部分数据 |
| `<文件名>.part.segments` | 多连接部分数据 |
| `<文件名>.part.meta` | 续传验证信息与已提交区间 |

损坏的设置或记录会隔离为 `*.bad`。已完成文件被移动或删除后，后台检查会标记「文件缺失」，可重新下载。

续传需服务端支持可靠 Range 和有效版本校验，否则从头下载。分片仅恢复已提交区间，暂停或崩溃后可能重下未提交部分；旧连续 `.part` 保持单连接续传。

降级前应完成或清理分片及待切换链接的任务，并备份记录；旧版本不能恢复这些中间状态。
