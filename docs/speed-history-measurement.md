# 速度历史的采样与开销

2026-11-22，Windows/amd64，Go 1.27.3，Intel Core i9-14900HX。测试使用虚拟时钟和本地服务，无外部下载。

每任务延迟分配一个 120 点环形缓冲。当前结构为 4872 字节（每点 40 字节，另含环索引和采样基线），不含任务对象、字符串、分配器开销和临时详情副本。按 1000 / 10000 个已分配缓冲计算，原始缓冲分别为 4,872,000 / 48,720,000 字节；移除立即清空任务的缓冲引用。普通 `Snapshot()` 的 Item 不含历史。

从仓库根目录执行（PowerShell/Bash 相同）：

```sh
go test ./internal/download -run TestHistory -count=1
go test ./internal/download -run '^$' -bench '^BenchmarkHistorySnapshot$' -benchmem -benchtime=100ms
```

本机一次测量，所有任务都填满历史：

| 任务数 | Snapshot 耗时 | 分配字节/次 | 分配次数/次 |
| --- | ---: | ---: | ---: |
| 1000 | 67,473 ns | 598,034 | 1 |
| 10000 | 942,629 ns | 5,922,817 | 1 |

分配为任务快照切片，不是每任务 120 点历史的复制。按 ID 查询最多复制 120 个点。数据仅说明这台机器上的内存结构和短基准结果，不代表其他平台的性能保证。

采样由引擎维护定时器触发，与 UI 构建次数无关，每任务最多每秒一次。与计划下载共享定时器，并遵守应用启动屏障；真实经过时间取 Go 单调时钟，墙钟只用于时间轴和时间变化检测。全部连接收到的字节进入统一累计，重试流量进入速度而不重复增加 Done；排队、暂停、失败、完成的正常样本为零。

首次无差值、间隔超过两秒、计数异常或时钟跳变标为缺口；不补采休眠期间的数据，不插值跨越缺口。墙钟回拨清理未来点，120 秒之外的点淘汰。历史不进入任务记录，重启后从空历史开始；退出停止定时器。
