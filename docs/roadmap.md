# 下载器迭代计划

创建：2026-10-28；最近更新：2026-11-22

状态：下载控制、队列调度、可靠性增强及日常操作功能已实现；拖放和剪贴板已完成 Windows 原生手工验收，其他平台尚未实测。托盘仍有原生验收待完成，浏览器扩展尚未实施。勾选项表示已经实现并通过相应验收；具体版本号与发布时间在发布时确定。当前已实现功能以 [README](../README.md#功能) 为准。

## 当前基础

已有 HTTP/HTTPS 下载、批量添加、并发队列、暂停与断点续传、自动重试、代理、任务持久化、列表与卡片视图、搜索筛选、多选操作和完成通知。

后续优先完善下载控制、任务配置与后台使用体验，再扩展下载引擎。

## 迭代顺序

| 阶段 | 目标 | 主要功能 |
| --- | --- | --- |
| 第一阶段：下一轮迭代 | 更好地控制和查看下载 | 全局限速、高级新建任务、任务详情 |
| 第二阶段 | 适合长期运行和批量任务 | 托盘与后台下载、队列优先级、计划下载 |
| 第三阶段 | 增强可靠性和下载能力 | 单任务限速、文件校验、失效链接更新、多连接分片、浏览器扩展 |
| 按需穿插 | 减少日常重复操作 | 导入导出、分类目录、拖放添加、剪贴板提示、诊断日志 |

## 第一阶段：下载控制与任务配置

### 1. 全局限速

- [x] 支持设置所有任务合计的下载速度上限，并提供不限速选项。
- [x] 下载过程中修改限制能够生效，设置在重启后保留。
- [x] 多任务共享额度，限速等待可取消，暂停与退出能及时响应；主动限速不会被误判为连接停滞。

验收重点：用本地 HTTP 服务器验证多任务合计速度、动态调节和取消行为，允许合理的短时突发与测量误差。

### 2. 高级新建任务

- [x] 在现有快速添加入口之外，提供单任务的保存目录与文件名配置。
- [x] 支持 Referer、Cookie 和自定义请求头，复用现有代理与认证能力。
- [x] 自定义文件名仍遵守最终文件、`.part` 与 `.part.meta` 的冲突预留规则。
- [x] Cookie、Authorization 等敏感字段不写入普通 JSON、复制内容或日志；需要跨重启保存时通过凭据存储处理。
- [x] 下载引擎管理 Range、If-Range 和 Accept-Encoding 等影响续传正确性的字段；自定义请求头不会破坏续传或向无关重定向目标泄露认证信息。

验收重点：本地测试覆盖自定义请求头、认证、重定向、目录不可写和同名文件；原有批量快速添加仍可使用。

### 3. 任务详情

- [x] 集中展示链接、保存路径、文件大小、已下载量、速度、预计剩余时间、创建与完成时间、重试次数和续传能力。
- [x] 提供完整错误说明与复制诊断信息的入口，诊断信息去除凭据。
- [x] 明确未知大小、尚未获取续传能力、文件缺失等状态，避免显示误导性数值。

验收重点：覆盖下载中、排队、暂停、失败、完成和未知长度状态；详情打开时保持更新。速度曲线的后续实施记录见下方。

### 第一阶段实施记录（2026-10-28）

- **入口**：设置 → 常规 → 全局限速；主界面 → 高级新建；任务行、卡片的详情按钮及右键菜单 → 任务详情。
- **限速**：所有任务共享额度，0 表示不限速；动态调整不重新建立连接，短时突发控制在小块读取范围内。
- **高级任务**：文件名与目录可单独指定；同一链接的已停止任务可补填请求头，保留原保存路径和进度。所有自定义请求头仅存内存，首期不提供跨重启的凭据存储；重启后通过同一入口补填。
- **详情**：保留自动重试次数，区分未知和不支持续传；诊断文本去除 URL 认证与查询参数值，错误信息过滤请求凭据。任务时长包含暂停时间，速度曲线仍列在后续增强项中。
- **验证**：在 Windows/amd64 上完成 `CGO_ENABLED=0` 的全量测试与构建、`go tool mygo vet .`，并对下载、应用、设置和存储包执行 race 检查。网络用例使用本地 HTTP 服务，UI 用例覆盖输入、焦点、关闭重开、详情更新和诊断复制。
- **视觉检查**：生成并检查浅色、深色主题的真实像素快照，包含 960×640 最小窗口、125% 缩放下的高级表单及滚动内容、任务详情、错误详情和限速设置；同步更新 README 的两套界面截图。
- **验证范围限制**：未手动验证原生窗口中的文件选择器、系统剪贴板等行为，未在 macOS/Linux 实机运行。

## 第二阶段：后台运行与队列调度

### 4. 托盘与后台下载

- [ ] 提供关闭窗口后进入托盘继续下载的选项，并保留明确的退出入口。
- [ ] 托盘支持恢复窗口、查看下载概况、全部暂停和全部继续。
- [ ] 真正退出时仍正常取消工作任务、保存进度并释放单实例资源。

验收重点：先核实当前 MyGo 与各平台的托盘、窗口隐藏和恢复能力，再分平台实施；在目标系统实测关闭、恢复、退出和通知行为，未支持的平台明确说明。

实施记录（2026-11-22）：托盘菜单、两秒概况刷新、持久设置、关闭隐藏及退出取消处理已实现，替身测试覆盖失败退化和幂等清理。Windows 原生实例已启动，但因桌面持续输入暂停验收，用户选择先继续代码；macOS/Linux 无实机条件。各平台生产入口暂时禁用，保持正常退出，本项验收复选框尚不勾选。

### 5. 队列优先级

- [x] 支持将任务置顶、上移和下移，优先启动指定的排队任务。
- [x] 调度顺序独立于列表的名称、大小和时间排序，并在重启后保留。
- [x] 首期只调整尚未开始任务的顺序，已运行任务继续下载。

验收重点：验证并发上限、暂停后继续、删除队列项及重启恢复后的启动顺序。

实施记录（2026-11-22）：独立 QueueOrder 持久化与稳定修复，完整等待队列的相邻移动，暂停锚点保留、新项尾插。受控本地 HTTP 验证并发与真实启动顺序；ui.Tester 覆盖名称排序、过滤后移动、键盘连续操作和菜单禁用。详情快照覆盖两套主题、960×640 与 125% 缩放。

### 6. 计划下载

- [x] 支持指定开始时间，以及允许下载的每日时间段。
- [x] 调度与手动暂停、优先级和并发数协调，避免自动恢复用户主动暂停的任务。
- [x] 持久化计划，并定义错过开始时间、应用重启和系统时间变化后的处理方式。

验收重点：通过可替换的时钟验证时间边界。首期只在应用运行期间调度，不包含唤醒电脑或自动启动应用。

实施记录（2026-11-22）：Clock/Timer 替身与本地 HTTP 覆盖时段起止、跨午夜、跳时、回拨、休眠返回、失败、退出恢复、优先级与 worker 唯一性。持久化手动暂停与单调开始条件；Windows 读取当前系统时区，其他系统在调度线程刷新时区数据库。高级新建和详情提供计划编辑，ui.Tester 覆盖错误输入、保存重开与过期异步结果。仅验证当前 Windows 主机的时间转换，未更改主机时钟或时区。

## 第三阶段：可靠性与引擎扩展

### 7. 单任务限速

- [x] 在全局限速基础上，允许为单个任务设置独立上限。
- [x] 单任务与全局限制同时生效，运行中修改不会丢失进度。

实施记录（2026-11-22）：新增高级表单/详情的 KB/s 编辑，任务上限随记录保存；联合额度、短读退款及变更唤醒由确定性测试覆盖，本地 HTTP 验证合计上限、单任务上限、动态不重连和逐字节正确性，一字节每秒等待的暂停/移除/退出在 500ms 内取消。

### 8. 文件完整性校验

- [x] 允许输入预期 SHA-256，下载后在后台计算并显示匹配或不匹配。
- [x] 区分下载完成与校验结果；校验可取消，大文件校验不阻塞界面。

实施记录（2026-11-22）：使用独立串行 worker 和 256 KiB 分块，取消/移除/退出等待文件释放；generation 和读取前后文件身份检查拒绝晚到结果。重启将历史结果与当前待校验区分；不匹配保留文件、不自动重下。本地文件及 HTTP 测试覆盖匹配、错误、取消、替换、摘要变更和传输完成通知。

### 9. 更新失效链接

- [x] 为暂停或失败的任务更换过期下载地址，保留原任务记录与目标路径。
- [x] 只有能够确认新旧文件版本一致时才沿用部分数据；不能确认时重新下载，避免拼接不同内容。

实施记录（2026-11-22）：完整前缀逐字节验证、同源同路径和强验证器门槛；源修订/待重置及完成检查点采用原子替换，故障注入覆盖提交、截断及重启。详情/右键入口支持取消与显式继续，新认证独立输入且跨源剥离。网络测试只使用本地服务。

### 10. 多连接分片下载

- [x] 探测服务器是否支持有效的 Range 响应，不支持时回退到单连接。
- [x] 实现分片调度、分片进度持久化、暂停恢复、失败重试和完成校验。
- [x] 各连接验证响应范围、总长度与文件版本，统一遵守限速、代理和取消规则。
- [x] 定义单任务连接数与全局连接数上限，使用可控的本地服务验证正确性并衡量吞吐收益。

实施记录（2026-11-22）：默认单连接、每任务 1–8 / 全局 1–64；独立稀疏文件、Sync 后原子区间提交、完整覆盖发布及源更新逐区间比对。HTTP/SOCKS5、限速、取消与故障恢复由本地测试覆盖。多连接不保证提速，参见 [测量方法与结果](multi-connection-measurement.md)。

### 11. 浏览器扩展接管下载

- [ ] 先确定浏览器扩展与桌面应用之间的通信方式，以及链接、文件名、请求头的传递格式。
- [ ] 首期支持用户主动将链接发送到下载器，再评估自动接管下载。
- [ ] 验证应用未启动、重复链接、认证数据传递和连接失败等情况。

## 可按需穿插的功能

- [x] **批量导入与导出**：导入 UTF-8 TXT，预览并确认后重新去重；导出所选或全部任务的 v1 脱敏清单，明确不作备份。容量、取消、部分失败、路径预留和认证由本地测试覆盖。
- [x] **分类与目录规则**：按扩展名或域名的首条启用规则选目录，显式单任务目录优先；默认预填仍参与匹配。IDNA、子域边界、规则持久化、输入验证、不可写目标、认证补填与响应改名由本地测试覆盖；编辑器保留重排焦点并提供命中预览。
- [x] **拖放添加**：实现 URI/Text/TXT 的有界预览、统一确认添加和焦点恢复，自动化用例覆盖重复构建与取消。2026-11-22 恢复 Windows 原生验收，直接观测 Chrome 链接投放，用户确认 TXT、取消及不支持类型检查通过；保留粘贴/导入替代入口，见 [验收记录](native-transfer-acceptance.md)。
- [x] **剪贴板链接提示**：默认关闭、事件监听、1 MiB 读取后限制、256 盐化指纹 LRU、最新候选替换和确认添加。假服务及 ui.Tester 覆盖关闭/退出、晚回调、自复制、去重、焦点与认证；2026-11-22 用户确认 Windows 原生提示、重复复制和设置关闭检查通过，见 [验收记录](native-transfer-acceptance.md)。
- [x] **诊断日志导出**：记录状态、重试、HTTP 状态及代理路径失败的安全枚举；采集前去掉凭据/查询串，不采集任意错误文本。1000 条/1 MiB/每条 2 KiB 有界缓存，后台原子 JSON 导出，本地 HTTP/代理、并发快照和取消/失败保留旧文件由自动化覆盖。
- [x] **速度曲线**：详情展示最近 120 秒、至多 120 点的内存历史，汇总实际网络接收量与重试流量；零速、休眠缺口、时钟回拨、生命周期与 UI 更新由自动化覆盖，双主题样例覆盖空数据、暂停、完成、峰值及缺口。大量任务快照不复制历史，见 [测量记录](speed-history-measurement.md)。

## 暂不优先的方向

BT／磁力、HLS 等视频流解析需要引入新的下载引擎或专门的媒体处理流程，维护成本较高，暂列为独立方向，后续有明确需求再评估。

## 实施与验收约定

- 保持现有包边界，UI 与平台服务放在 `internal/app`，下载能力放在 `internal/download`；设置和记录扩展保持旧数据兼容。
- 涉及 UI、窗口行为或 MyGo API 时，先阅读 [MyGo 维护技能](../.agents/skills/mygo-maintenance/SKILL.md)，查阅当前依赖源码；框架能力尚未核实的功能不视为已可用。
- 按 [项目协作规范](../AGENTS.md#验证与测试) 和 [README 验证说明](../README.md#验证与视觉快照) 执行相应测试、静态检查和视觉快照；网络测试使用本地服务。
- 每完成一项，勾选对应任务并同步 README 的功能和限制说明；涉及原生系统能力时，记录实际验证的平台与仍未验证的行为。
